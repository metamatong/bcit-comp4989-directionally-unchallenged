# Project walkthrough

1. Open the app and explain that all available floor plans come from official BCIT Burnaby sources.
2. Browse the campus library and open an original PDF, its PNG and geometry JSON.
3. If Gemini is configured and quota is available, upload a real campus photo. Show the preview and explain the per-photo send confirmation.
4. Submit optional context/building information with the photo. Gemini first shortlists plans, then compares selected details and geometry.
5. Review any possible region, its observable matches, uncertainty and source links. Confirm only if it agrees with the actual surroundings. An insufficient-evidence result is acceptable and should lead to another view.
6. Open Analysis activity to show completed comparisons and evidence references. Clear analysis to remove the result.

If provider configuration, quota or availability prevents a request, show that message and the source library. Do not present test fixtures or mocked responses as successful live localization.

There are no fictional landmarks, synthetic routes, mode choices, closure simulations or sample-photo controls. Walking directions and campus accuracy remain unverified. No app or coursework has been published/submitted.
